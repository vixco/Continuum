KAIRO

Desktop-Native Ambient AI Assistant
A local-first AI that watches your screen, listens to your voice, thinks when it matters, and acts on your behalf — all running on your Windows PC.
👁️
Layer 1
Senses
Always On · Free
Watches your screen and listens to your mic 24/7. Takes a screenshot every few seconds, transcribes speech, and checks which app you're using. Produces a structured "perception frame" — a snapshot of what's happening right now. Runs entirely on your machine. No data leaves your PC.
Moondream (Vision AI) Whisper (Speech-to-Text) Windows API (Context) Screenshot every 2–5s
▼ Perception frames flow up ▼
⚖️
Layer 2
Triage
Local LLM · Near-Free
The gatekeeper — decides if something is worth attention. A small AI model (Qwen 3 8B) reads each perception frame and makes a snap decision in under 1 second: ignore it, remember it silently, whisper a quick response, or wake up the big brain. This is what keeps costs near zero — 95% of frames get filtered out here.
Qwen 3 8B (local) llama.cpp ~960ms per decision 95% accuracy 5 decision types
▼ Only important events pass through (~5%) ▼
🧠
Layer 3
Orchestrator
Claude Opus · Pay-per-use
The brain — only wakes up when real thinking is needed. Claude Opus 4.6 (Anthropic's most powerful AI) is launched as a subprocess via the official CLI. It receives the current context + relevant memories, reasons about what to do, speaks back to you, and can delegate complex tasks to workers. Streams responses in real-time for low latency.
Claude Opus 4.6 Official CLI (subprocess) Stream-JSON protocol Episodic + Semantic Memory LanceDB vectors
▼ Commands flow down — spawns workers for complex tasks ▼
⚡
Layer 4
Workers
Claude Code · Task-based
The hands — does the actual work. Headless Claude Code sessions that can write code, fix bugs, manage files, open apps, run terminal commands, and interact with your Windows desktop. Multiple workers can run in parallel. Each has access to tools via the MCP server.
Claude Code (headless) MCP Tool Server Windows Automation File System Shell Commands Parallel execution

💰 Cost per Layer

Layer 1 — Senses $0 (local models)
Layer 2 — Triage $0 (local LLM)
Layer 3 — Orchestrator ~¢2–5 per wake-up
Layer 4 — Workers ~¢5–50 per task

🔑 Key Principles

100% local-first — senses and triage never leave your PC. No telemetry, no cloud dependency for basic operation.
Cost scales with intelligence — cheap models handle simple tasks, expensive models only wake for complex reasoning.
Official CLI only — Claude is invoked via the official claude CLI as a subprocess. No API keys, no token scraping.
Self-healing — a dedicated repair agent can diagnose and fix its own component failures automatically.
