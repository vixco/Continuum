## Global Constraints

- Cargo strictly serial, foreground. Gates per task: `cargo test -p continuum-core --lib` AND `cargo test -p continuum-core --no-default-features --lib` (desktop parity), `cargo clippy -p continuum-core --all-targets -- -D warnings`, `cargo fmt --all` + `-- --check`. Never full-workspace builds.
- Non-negotiables: #3 every knob in config (§6 defaults are normative), #5 health hooks per §7, #7 MCP additive-only (this plan touches no MCP).
- New modules behind the `runtime` feature ONLY where native-dependent; `senses/privacy.rs` and pure types are UNGATED (spec §3). `regex` becomes an unconditional continuum-core dep.
- Privacy ordering is absolute: Task 1 lands before any new collector persists anything.
- Commit style: `feat(core): …` per task; update `CHANGELOG.md` once at the end of Plan C, not per task.

### Task A1: Privacy filter module (spec §4.1, §6)
Create `crates/continuum-core/src/senses/privacy.rs` (ungated): `PrivacyFilter` with scrub_text (secret scrubbers, free-text-only scope rule), scrub_path (home→`~`, username redaction), zone resolution `{match_process?, match_title_keyword?, zone}` + legacy-list load-time synthesis (process names→never_observe, title keywords→local_only; union, stricter wins; new private-browsing defaults), `Zone` + propagation helper `strictest(zones)`, sentinel constants. Config `[privacy]` incl. toggles struct {mic,screen,files,git,pause_all}. Tests: secret corpus in→out clean, false-positive corpus (git OID/UUID/sha256 survive), idempotence, zone matrix, legacy synthesis.

### Task A2: Privacy enforcement at existing emit points (spec §4.1 applied-at list, §4.11 screenshots)
Wire the filter into: ContextWatcher observation build (sentinel semantics for never_observe — process "[excluded]", defined dwell/switch/salience behavior per §4.1), vision caption + monitor zone via per-monitor visible-window sweep (EnumWindows+GetWindowRect joined to MonitorWorldState; never_observe monitors: no caption, no screenshot file), audio transcript, `raw_log.write_frame` inputs, every `LiveContextHub.record_*` payload (scrub at collector emit, before the hub fork). Toggle enforcement: each watcher checks its `[privacy]` toggle; pause_all gates the frame loop; toggle changes emit a system event (queued for A6's channel — until then log-only). Tests: sentinel frame continuity (no stale-window persistence), monitor zone inheritance, toggles stop emission.

### Task A5: Git collector (spec §4.4)
`senses/git_watch.rs` (runtime-gated watcher pattern): active CONFIRMED project only; consolidated `git status --porcelain=v2 --branch` + `git log -1` probe, CREATE_NO_WINDOW, command_timeout_secs; mtime gate on ref-derived facts only (dirtiness always polls); post-hysteresis switch probe + min_spawn_interval; extended ProjectWorldState (schema version bump); change-only events (commit/branch_switch/conflict/dirty_change); subject scrubbed, OID exempt; project zone enforced. Failure modes per spec: version-probe→disabled-with-reason (should_restart=false), gitdir-file worktrees, empty/detached→branch null. Tests: porcelain parsing, gate split, failure modes (probe absent, detached), zone gating.

### Task A6: Events-writer task + context_events + FTS + dedupe (spec §3 transport, §4.6)
`memory/events.rs` (runtime-gated): `ContextEvent` struct + closed event_type registry (per-source table, spec-normative), sensitivity enum {local_only, cloud_allowed}; `mpsc::Sender<ContextEvent>` cloned into collectors (A2 toggles, A3 switches, A5 git; file events in A7); dedicated writer task: bounded queue (queue_cap, drop-oldest + events_dropped coalesce row), dedupe (template-source key WITH normalized_summary — normalization exactly per spec; screen/audio key WITHOUT summary; ts_last anchor; count_cap/span_cap), batch INSERT/UPDATE, `(dedupe_key, ts_last)` index + LRU, `context_events_fts` FTS5 external-content + restricted triggers; retention rotation with raw log. All DDL in raw_log.rs. Wire A2/A3/A5 buffered producers onto the channel. Tests: dedupe matrix (both key variants, anchor, caps), overflow coalesce, FTS consistency after collapse-update, migration idempotence, registry stability (serde round-trip of every type).

### Task A7: File watcher (spec §4.5)
`senses/file_watch.rs` (runtime-gated, notify): confirmed roots only, default OFF; debounce, ignore-globs, rename pairing, storm coalescing (`files_bulk_change` at storm_threshold), per-root unavailable states + rearm backoff, overflow resync; paths scrubbed; project zone enforced; events onto A6 channel. Tests: debounce/pairing/storm logic (pure parts), root-unavailable state machine.

### Task A8: Idle controls + publisher content-versioning + health wiring (spec §4.11 idle/publisher, §7)
Shared AtomicU64 cadence pattern (documented in code as the sanctioned pattern): idle controller adjusts capture interval + vision min-interval (idle_vision_interval_ms, 0=paused) when idle > idle_pause_after_secs; restore on input OR voice wake OR hotkey OR do_wake (wake-during-pause forces one capture+vision pass or stamps stale); triage idle gate = mechanical (error/audio only) — implemented as a frame-loop skip predicate, no triage code change; idle_start/idle_end system events. Publisher: content-version counter (bump rules per spec; no unchanged-ring events during idle). Health: wire the dead should_restart hooks (LiveContextHub, ContextWatcher) + register all new watchers in the health snapshot; recovery procedures added to docs/self-healing.md. Tests: idle state machine incl. voice-wake restore, content-version bump rules.
