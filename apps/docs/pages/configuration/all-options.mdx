# All config options reference

Every setting Kairo reads, grouped by section. File: `~/.kairo/config/default-models.toml`.

## `[vision]`
| Key | Type | Default | Purpose |
|---|---|---|---|
| `name` | string | `"SmolVLM-256M"` | human-facing label |
| `model_path` | string | blank | search `~/.kairo/models/vision` if blank |
| `gpu_enabled` | bool | auto | force ONNX-GPU |
| `input_width` | int | 384 | vision input W |
| `input_height` | int | 384 | vision input H |

## `[screen]`
| Key | Type | Default |
|---|---|---|
| `interval_secs` | int | 3 |
| `capture_width` | int | 1280 |
| `capture_height` | int | 720 |
| `save_screenshots` | bool | true |

## `[audio]`

## Environment variables

| Var | Purpose |
|---|---|
| `KAIRO_MODELS_DIR` | override models root |
| `KAIRO_PIPER_BIN` | override Piper binary path |
| `KAIRO_DATA_DIR` | override `~/.kairo` root |
| `KAIRO_MCP_BIN` | explicit `kairo-mcp.exe` path |
| `KAIRO_WORKER_DRY_RUN` | set to `1` for worker transcript simulation |
| `ANTHROPIC_API_KEY` | passed through to Claude Code |
