# What stays local

Kairo's privacy model is simple: **everything is local unless you ask the orchestrator to think**. Even then, only the relevant wake context goes to the cloud — never the raw stream.

## Always local

- Screenshots (at `~/.kairo/memory/screenshots/` if you have `screen.save_screenshots = true`)
- Microphone audio (never written to disk — only whisper transcripts are stored)
- Whisper transcripts (at `~/.kairo/memory/raw_log.sqlite`)
- Vision model (SmolVLM-256M runs in-process)
- Triage model (Qwen 3 8B runs in-process)
- TTS synthesis (Piper subprocess)
- Episodic memory (LanceDB at `~/.kairo/memory/episodic/`)
- Semantic memory (SQLite at `~/.kairo/memory/semantic.sqlite`)
- Logs (`~/.kairo/logs/`)
- Backups (`~/.kairo-backups/`)

Nothing in this list is ever uploaded anywhere.

## Leaves your machine only when triage wakes Opus

When triage decides `wake_orchestrator`, Kairo sends to the `claude` CLI (which sends it to Anthropic's API):

- The wake context (current frame + top-K retrieved memories + skill content + triage reason)
- The orchestrator system prompt
- Results of any tool calls Opus makes during the wake

The wake context is capped at ~4000 tokens. It contains text and optionally a single screenshot if Opus requests it via `perception_*` tools (not exposed yet — see [KNOWN_ISSUES.md](https://github.com/vixco/kairo-ai/blob/main/KNOWN_ISSUES.md)).

## When workers run

Workers are additional Claude Code sessions. Everything a worker reads is subject to the same flow: read locally, reason remotely, write remotely only what the tool lets it write.

## ElevenLabs (when enabled)

If you enable the ElevenLabs TTS backend (stubbed in alpha, not enabled yet), TTS text goes to ElevenLabs for synthesis. Disabling it keeps you fully local.

## Third-party endpoints

Kairo makes outbound HTTP to exactly three kinds of endpoints:

1. **`api.anthropic.com`** via the `claude` CLI — when the orchestrator or a worker wakes.
2. **GitHub / HuggingFace** during model download via `scripts/download-models.ps1`. Only at install time or when you explicitly trigger a reinstall.
3. **The configured TTS backend** (Piper is local; ElevenLabs is cloud when enabled).

No other outbound calls. The orchestrator's `web_fetch` tool is GET-only, capped at 50 KB, and blocks private IPs.

## Opt-out knobs

- **Pause perception entirely** from the tray menu — senses go silent.
- **Disable voice** → no mic capture.
- **Disable screenshots** → vision still runs on the bitmap in memory but nothing hits disk.
- **Disable model auto-download** → Kairo won't reach out to HuggingFace; bring your own models.
