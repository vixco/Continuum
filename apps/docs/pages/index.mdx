# Welcome to Continuum

**Continuum** is a desktop-native, local-first ambient AI assistant for Windows. It sees what you see, hears what you hear, remembers what matters, and acts only when the moment is right.

This is the documentation site for users and developers. If you want the architectural design doc, read [ARCHITECTURE.md](https://github.com/vixco/Continuum/blob/main/ARCHITECTURE.md) on the repo.

## What makes Continuum different

1. **Local first.** Senses, triage, voice synthesis, and memory all run on your machine. Only the orchestrator (Claude Opus 4.6) calls the cloud, and only when triage decides it's worth it.
2. **Legal and distributable.** Continuum uses Claude Code via its official headless CLI. No OAuth scraping, no reverse-engineered tokens.
3. **You own your brain.** Every piece of memory can be viewed, edited, exported, and deleted. Continuum never phones home.
4. **Swappable everything.** Vision model, triage LLM, TTS voice, STT engine, wake word — all configurable from the dashboard.
5. **Self-healing.** When something breaks, a Claude Code repair agent can diagnose and fix it from the dashboard.
