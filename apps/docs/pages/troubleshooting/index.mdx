# Troubleshooting

If something's not working:

1. **Click "Fix Issues"** in the dashboard Health tab. The [repair agent](/features/self-healing) can fix most common problems automatically.
2. **Check [common fixes](/troubleshooting/common-fixes)** for the usual suspects.
3. **Read the logs** at `~/.kairo/logs/<component>.log` or in the dashboard Logs tab. See [reading the logs](/troubleshooting/reading-logs).
4. **Reset to defaults** if nothing else works — see [resetting Kairo](/troubleshooting/reset).
5. **[Open an issue](https://github.com/PrincNL/kairo-ai/issues/new/choose)** with the bug-report template.

Before filing a bug, please check [KNOWN_ISSUES.md](https://github.com/PrincNL/kairo-ai/blob/main/KNOWN_ISSUES.md) — if your problem is already listed, star it; don't duplicate.
