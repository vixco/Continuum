# Troubleshooting

If something's not working:

1. **Click "Fix Issues"** in the dashboard Health tab. It can safely start an offline runtime; other problems are diagnosed and escalated with explicit next steps.
2. **Check [common fixes](/troubleshooting/common-fixes)** for the usual suspects.
3. **Read the logs** at `~/.continuum/logs/<component>.log` or in the dashboard Logs tab. See [reading the logs](/troubleshooting/reading-logs).
4. **Reset to defaults** if nothing else works — see [resetting Continuum](/troubleshooting/reset).
5. **[Open an issue](https://github.com/vixco/Continuum/issues/new/choose)** with the bug-report template.

Before filing a bug, please check [KNOWN_ISSUES.md](https://github.com/vixco/Continuum/blob/main/KNOWN_ISSUES.md) — if your problem is already listed, star it; don't duplicate.
